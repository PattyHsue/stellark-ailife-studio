📝 10 Knowledge Quizzes📝 10 題隨堂知識測驗

  1. When Python performs standard division `/`, what data type is always returned?當 Python 執行標準除法 `/` 時，回傳的結果必定是什麼資料型態？
    💡 Answer: Always `float` (floating-point), even `4 / 2` evaluates to `2.0`.💡 參考解答：永遠是 `float`（浮點數），就算 `4 / 2` 整除，結果也會是 `2.0`。
  2. Why can't the return value of `input()` be used in math calculations directly?為什麼 `input()` 取得的數值不能直接拿來做除法或乘法運算？
    💡 Answer: Because `input()` returns a `str` (text). You must convert it using `float()` or `int()` first.💡 參考解答：因為 `input()` 預設回傳的是文字字串 `str`，必須先透過 `float()` 或 `int()` 轉型成數值才能計算。
  3. `int()` converts text to an integer. Which function converts text to a decimal number?`int()` 將文字轉為整數，那麼哪一個函式負責將文字轉為帶小數點的浮點數？
    💡 Answer: `float()`, which handles numeric values with decimal points.💡 參考解答：`float()`，專門用來轉換並處理帶有小數點的數值。
  4. If the exchange rate `32.5` is converted using `int(32.5)`, what happens?如果把匯率 `32.5` 誤用 `int(32.5)` 轉換，會發生什麼事？
    💡 Answer: The decimal part is truncated, becoming `32`. In financial systems, this causes severe calculation errors.💡 參考解答：小數點後會被無條件捨去變成 `32`，在金融系統中會造成巨大的匯差錯誤。
  5. In an f-string, what does the format specifier `:.2f` mean?在 f-string 中，`:.2f` 代表什麼意思？
    💡 Answer: Format as a floating-point number (`f`) rounded to 2 decimal places.💡 參考解答：將數值以浮點數（`f`）格式輸出，並四捨五入保留小數點後 `2` 位。
  6. Why do we set a 5% fee rate as `0.05` instead of `5` in code?在金融程式中，為什麼我們通常將 5% 手續費設定為 `0.05` 而非 `5`？
    💡 Answer: Because 5% equals 5/100 = 0.05. Storing the decimal ratio directly avoids unit confusion during multiplication.💡 參考解答：因為百分比本質上是分數（5/100 = 0.05），直接使用小數比例在乘法計算時最安全，不會搞混單位。
  7. What data type and value does the expression `5 > 3` produce?運算式 `5 > 3` 會產生什麼資料型態與結果？
    💡 Answer: `bool` (Boolean), and the value is `True`.💡 參考解答：布林型態（`bool`），結果為 `True`（真）。
  8. When do we use `elif` instead of writing multiple separate `if` statements?什麼時候我們應該使用 `elif` 而不是寫好幾個獨立的 `if`？
    💡 Answer: When the conditions are mutually exclusive (only one branch should execute, and once matched, the rest are skipped).💡 參考解答：當多個條件彼此互斥（多選一，只要其中一個成立就不再往下檢查其他條件）時使用 `elif`。
  9. What is the difference between `=` and `==` in Python?在 Python 中，單等號 `=` 與雙等號 `==` 有什麼關鍵差異？
    💡 Answer: `=` is assignment (storing a value in a variable); `==` is equality comparison (checking if two values are equal).💡 參考解答：`=` 是賦值（把右邊的值放進左邊的變數）；`==` 則是相等比較（檢查左右兩邊的值是否相等，回傳 True/False）。
  10. Why should constants like `TAX_RATE = 0.05` be declared at the top of the file?為什麼像 `TAX_RATE = 0.05` 這樣的商業邏輯常數應該宣告在程式最上方？
    💡 Answer: Clean Code best practice: avoids 'Magic Numbers' scattered in code and lets you update the rate in one single place.💡 參考解答：遵循 Clean Code 原則：避免在程式碼各處散落不明所以的「魔術數字（Magic Numbers）」，未來調整費率只需改一個地方。
