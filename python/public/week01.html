📝 10 Knowledge Quizzes📝 10 題隨堂知識測驗

  1. What header level does `#` represent in Markdown?在 Markdown 語法中，`#` 代表什麼？
    💡 Answer: Represents Header level. One `#` is H1 (largest title), two `##` is H2, three `###` is H3.💡 參考解答：代表標題層級（Header）。一個 `#` 是最大標題 H1，兩個 `##` 是 H2，依此類推。
  2. How do you create *italic* and **bold** text in Markdown?在 Markdown 中如何製作斜體與粗體文字？
    💡 Answer: Use single asterisks `*italic*` for italic, and double asterisks `**bold**` for bold.💡 參考解答：在文字前後加上一個星號 `*斜體*` 為斜體，加上兩個星號 `**粗體**` 為粗體。
  3. What is Google Colab's core advantage for beginners?Google Colab 對初學者而言最大的核心優勢是什麼？
    💡 Answer: Zero installation required! Google provides free cloud computing resources (including GPUs) so you can write and run Python directly in your browser.💡 參考解答：完全免安裝環境！由 Google 提供免費雲端運算資源（含 GPU），打開瀏覽器就能直接撰寫並執行 Python。
  4. What is a Repository (Repo) in GitHub?在 GitHub 中，什麼是 Repository（儲存庫）？
    💡 Answer: A storage space where all your project code files, documentation, and full revision history are kept.💡 參考解答：用來存放專案所有程式碼檔案、說明文件以及完整修改歷史紀錄的雲端專案寶庫。
  5. What is Python's most fundamental output command?Python 最基礎的螢幕輸出指令是什麼？
    💡 Answer: `print()` — used to display text, numbers, or variable values on the screen.💡 參考解答：`print()`，用來將文字、數字或變數內容印出在螢幕上。
  6. What does a Commit do in Git version control?在版本控制中，Commit（提交）的作用是什麼？
    💡 Answer: Confirms and saves your current changes, creating a permanent checkpoint in the project's timeline.💡 參考解答：確認並儲存目前的修改內容，在專案歷史時間軸中建立一個永久的存檔點。
  7. What is the Markdown syntax for an interactive task checklist?Markdown 的任務勾選清單語法是什麼？
    💡 Answer: Use `- [ ]` for an incomplete task and `- [x]` for a completed task.💡 參考解答：使用 `- [ ]` 代表未完成任務，使用 `- [x]` 代表已完成任務。
  8. What is the keyboard shortcut to execute a cell in Google Colab?在 Colab 或線上編輯器中執行程式格的快捷鍵是什麼？
    💡 Answer: `Shift + Enter` (run and move to next cell) or `Ctrl + Enter` (run current cell).💡 參考解答：`Shift + Enter`（執行並移至下一格）或 `Ctrl + Enter`（執行目前程式格）。
  9. Which tech company currently owns GitHub?目前哪一家科技巨頭擁有 GitHub？
    💡 Answer: Microsoft (acquired in 2018).💡 參考解答：微軟（Microsoft）。
  10. What is the file extension for a Colab / Jupyter Notebook?Colab 與 Jupyter 筆記本的檔案副檔名是什麼？
    💡 Answer: `.ipynb` (Interactive Python Notebook).💡 參考解答：`.ipynb`（Interactive Python Notebook 互動式 Python 筆記本）。
