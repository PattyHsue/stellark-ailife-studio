📝 10 Knowledge Quizzes📝 10 題隨堂知識測驗

  1. What is the main role of a Variable in programming?在程式設計中，變數（Variable）的主要角色為何？
    💡 Answer: A named container in memory that stores and holds data, which can be retrieved or updated at any time.💡 參考解答：記憶體中具名的「資料儲存水晶盒」，用來存放、讀取與隨時更新資料。
  2. In Python, what are the type names for integer, float, and string?在 Python 中，整數、浮點數與字串的型態英文縮寫為何？
    💡 Answer: `int` (integer), `float` (floating-point number), and `str` (string).💡 參考解答：`int`（整數）、`float`（浮點數/小數）與 `str`（字串）。
  3. Why does `print('10' + '20')` produce `'1020'` instead of `30`?為什麼 `print('10' + '20')` 的結果是 `'1020'` 而不是 `30`？
    💡 Answer: Because quotes make Python treat them as strings (text). The `+` operator concatenates text instead of adding numbers.💡 參考解答：因為加上引號後 Python 會將它們視為文字（字串 `str`），`+` 號對字串會執行「文字拼接」而非數學加法。
  4. What data type does `input()` ALWAYS return, no matter what the user types?無論使用者在鍵盤輸入什麼，`input()` 回傳的預設資料型態必定為何？
    💡 Answer: Always `str` (string). Even if the user types `50`, Python receives `'50'`.💡 參考解答：永遠是 `str`（字串）。即使輸入數字 `50`，拿到的也是文字 `'50'`。
  5. What disaster happens if you name a variable `print = 10`?如果把變數取名為 `print = 10` 會發生什麼災難？
    💡 Answer: You overwrite Python's built-in `print` function with the integer 10, causing `TypeError: 'int' object is not callable` on future print calls.💡 參考解答：會覆蓋掉 Python 內建的 `print()` 輸出函式，導致後續呼叫 `print()` 時發生 `'int' object is not callable` 崩潰錯誤。
  6. How do you convert the string `'50'` into an integer for calculation?如何將字串 `'50'` 轉換為可以進行數學計算的整數？
    💡 Answer: Use Python's built-in type-casting function: `int('50')`.💡 參考解答：使用 Python 內建的型別轉換函式：`int('50')`。
  7. When using f-string formatting, inside which brackets must variables be placed?使用 f-string 格式化字串時，變數或算式必須放在哪種括號內？
    💡 Answer: Curly braces `{}`, for example: `f"Hello {user_name}"`.💡 參考解答：大括號 `{}` 中，例如：`f"Hello {user_name}"`。
  8. What is the Pythonic shortcut to print 30 equal signs as a divider line?在 Python 中，印出 30 個等號作為分隔線最優雅的寫法是什麼？
    💡 Answer: Use string multiplication: `print('=' * 30)`.💡 參考解答：使用字串乘法：`print('=' * 30)`。
  9. Why do software engineers prefer meaningful variable names like `user_age` over `a` or `b`?為什麼業界強調使用具語意意義的變數名稱（如 `user_age`）而非 `a`, `b`, `c`？
    💡 Answer: Clean Code principle: descriptive names make code self-documenting so teammates and your future self immediately understand its purpose.💡 參考解答：這是 Clean Code（整潔程式碼）的核心原則，具可讀性的命名能讓團隊與未來的自己一眼看懂資料用途。
  10. In what scenario does `TypeError` usually occur?什麼情況下通常會觸發 `TypeError` 錯誤？
    💡 Answer: When performing an operation on incompatible data types, such as adding a `str` and an `int` directly without conversion.💡 參考解答：當你嘗試對不相容的資料型態進行運算時（例如未經轉型就直接將字串 `str` 與整數 `int` 相加）。
