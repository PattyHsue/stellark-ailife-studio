📝 10 Knowledge Quizzes📝 10 題隨堂知識測驗

  1. What is a module in Python?在 Python 中，什麼是「模組（Module）」？
    💡 Answer: A `.py` file containing reusable functions, classes, and variables that can be imported into other programs.💡 參考解答：一個包含可重用函式、類別與變數的 `.py` 檔案，可透過 `import` 引入其他程式中使用。
  2. What is the difference between `import math` and `from math import sqrt`?`import math` 與 `from math import sqrt` 在呼叫時有何不同？
    💡 Answer: `import math` requires the prefix `math.sqrt()`; `from math import sqrt` lets you call `sqrt()` directly.💡 參考解答：`import math` 呼叫時需加上前綴 `math.sqrt()`；`from math import sqrt` 則可直接呼叫 `sqrt()`。
  3. What does `import random as r` do?`import random as r` 的作用是什麼？
    💡 Answer: Imports the `random` module under the alias `r`, so you can write `r.randint(1, 10)`.💡 參考解答：為 `random` 模組建立別名 `r`，方便後續以簡短的 `r.randint(1, 10)` 呼叫。
  4. What is the Python Standard Library?什麼是 Python 標準函式庫（Standard Library）？
    💡 Answer: A rich collection of built-in modules (`math`, `random`, `datetime`, `os`, `json`, etc.) included with Python out of the box.💡 參考解答：隨 Python 安裝即內建的官方工具模組群（如 `math`、`random`、`datetime`、`os`、`json` 等），無需額外 `pip install`。
  5. What is the difference between `random.choice(seq)` and `random.sample(seq, k)`?`random.choice(seq)` 與 `random.sample(seq, k)` 有何差別？
    💡 Answer: `choice()` picks 1 random item; `sample(seq, k)` picks `k` unique items without replacement.💡 參考解答：`choice()` 隨機抽取 1 個元素；`sample(seq, k)` 則會「不重複地」隨機抽出 `k` 個元素（非常適合樂透抽獎）。
  6. What is the purpose of `if __name__ == '__main__':` in a Python file?在 Python 檔案中寫 `if __name__ == '__main__':` 的用途是什麼？
    💡 Answer: It ensures the code block inside only runs when the file is executed directly, and NOT when it is imported as a module by another file.💡 參考解答：確保該區塊內的測試或主程式只在「直接執行此檔案」時才會運作，被其他檔案 `import` 時不會自動執行。
  7. What does `json.dumps(data)` do?`json.dumps(data)` 的作用是什麼？
    💡 Answer: Serializes a Python dictionary or list into a JSON-formatted string.💡 參考解答：將 Python 的字典或列表物件轉換（序列化）為標準 JSON 格式字串。
  8. Why use `os.path.join()` instead of hardcoding `'folder\\file.txt'`?為什麼應該使用 `os.path.join()` 而不是手動用斜線拼接路徑？
    💡 Answer: Because Windows uses `\` while macOS/Linux use `/`. `os.path.join()` automatically uses the correct separator for the current OS.💡 參考解答：因為 Windows 與 macOS/Linux 的路徑斜線符號不同，`os.path.join()` 能自動根據作業系統產生正確的跨平台路徑。
  9. What does `datetime.now().strftime('%Y-%m-%d')` return?`datetime.now().strftime('%Y-%m-%d')` 會回傳什麼？
    💡 Answer: Today's date formatted as a string like `'2026-10-25'`.💡 參考解答：將目前日期格式化為 `'YYYY-MM-DD'`（例如 `'2026-10-25'`）的字串。
  10. Why is modular programming important in software engineering?為什麼「模組化程式設計」在軟體工程中如此重要？
    💡 Answer: It separates concerns, prevents giant unmaintainable files, enables code reuse, and makes team collaboration effortless.💡 參考解答：它能實現關注點分離（Separation of Concerns）、避免單一檔案過於龐大、提升程式碼重用率並方便團隊分工測試。
