Core Concept: class, __init__, self & Encapsulation大師觀念：class 藍圖、__init__ 建構子、self 與封裝

Object-Oriented Programming lets you model the world as interacting objects — each with its own data (attributes) and behavior (methods). The class is the blueprint; the instance is the real object.物件導向程式設計（OOP）讓你將真實世界模型化為彼此互動的物件——每個物件都擁有自己的資料（屬性 Attributes）與行為（方法 Methods）。類別（Class）是設計藍圖，實例（Instance）則是打造出來的真實個體。

class BankAccount: def __init__(self, owner, balance=0): self.owner = owner self.balance = balance def deposit(self, amount): self.balance += amount return f"💰 {self.owner} deposited ${amount}. Balance: ${self.balance}" acc = BankAccount("Patricia", 1000) print(acc.deposit(500))

📝 10 Knowledge Quizzes📝 10 題隨堂知識測驗

  1. What is Object-Oriented Programming (OOP)?什麼是物件導向程式設計（OOP）？
    💡 Answer: A programming paradigm that organizes software around objects that bundle data (attributes) and behaviors (methods) together.💡 參考解答：一種將「資料（屬性 Attributes）」與「操作行為（方法 Methods）」封裝在「物件（Object）」中來建構軟體的程式設計典範。
  2. What is the role of `__init__` inside a Python class?類別中 `__init__` 方法的角色是什麼？
    💡 Answer: It is the constructor method automatically invoked when a new object instance is created to initialize its attributes.💡 參考解答：它是「建構子（Constructor）」，當建立新物件實例時會被自動呼叫，用來初始化該物件的屬性。
  3. What does `self` represent as the first parameter of instance methods?實例方法的第一個參數 `self` 代表什麼？
    💡 Answer: It refers to the current object instance itself, allowing the method to access or modify that specific instance's attributes.💡 參考解答：代表「目前這個物件實例本身」，讓方法能夠存取或修改屬於該物件自己的屬性與其他方法。
  4. What is the difference between a class attribute and an instance attribute?「類別屬性（Class Attribute）」與「實例屬性（Instance Attribute）」有何差別？
    💡 Answer: Class attributes are shared across all instances of the class; instance attributes (`self.x`) belong uniquely to each individual object.💡 參考解答：類別屬性由所有物件共同分享；實例屬性（`self.x`）則由每個物件獨立擁有、互不影響。
  5. What is Encapsulation in OOP?什麼是 OOP 中的「封裝（Encapsulation）」？
    💡 Answer: Bundling data and methods inside a class while hiding internal state (e.g., `_balance`) behind safe public methods (`deposit()`, `withdraw()`).💡 參考解答：將資料與操作方法綁定在類別內，並隱藏內部細節（如 `_balance`），僅開放安全的公開介面（如 `deposit()`、`withdraw()`）供外部操作。
  6. What does the `__str__(self)` magic method control?`__str__(self)` 魔術方法控制什麼行為？
    💡 Answer: Defines the human-readable string representation of the object when passed to `print(obj)` or `str(obj)`.💡 參考解答：定義當物件被傳入 `print(obj)` 或 `str(obj)` 時，要如何轉換成易讀的字串呈現。
  7. What is the difference between `@classmethod` and `@staticmethod`?`@classmethod` 與 `@staticmethod` 有何差異？
    💡 Answer: `@classmethod` receives the class `cls` as its first parameter; `@staticmethod` receives no automatic `self` or `cls` parameter.💡 參考解答：`@classmethod` 第一個參數會自動傳入類別本身 `cls`（常用於工廠建構方法）；`@staticmethod` 則不接收 `self` 或 `cls`，相當於放在類別內的獨立工具函式。
  8. Why do Python developers prefix internal attributes with an underscore like `self._balance`?為什麼 Python 開發者常在內部屬性前加上底線（如 `self._balance`）？
    💡 Answer: It is the Python convention signaling that the attribute is private/internal and should not be modified directly from outside the class.💡 參考解答：這是 Python 社群的封裝慣例，用來提醒其他開發者此屬性屬於內部狀態，不應從類別外部直接強行修改。
  9. What is the relationship between a Class and an Instance?「類別（Class）」與「實例（Instance）」之間的關係是什麼？
    💡 Answer: A Class is the blueprint or cookie cutter; an Instance is a concrete object created from that blueprint.💡 參考解答：類別就像是建築藍圖或餅乾模具；實例則是根據該藍圖實際建造出來的房子或烤出來的餅乾。
  10. What are the main software engineering benefits of OOP?採用物件導向（OOP）對大型軟體工程有哪些核心好處？
    💡 Answer: Modularity, code reusability, state protection (encapsulation), and natural modeling of real-world domain entities.💡 參考解答：高模組化、高重用性、狀態保護（封裝性），並能自然地對應真實世界或遊戲中的角色與系統實體。
