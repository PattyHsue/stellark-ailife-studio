📝 10 Knowledge Quizzes📝 10 題隨堂知識測驗

  1. What does REST stand for in RESTful API?在 RESTful API 中，REST 代表什麼？
    💡 Answer: Representational State Transfer — a standard architectural style for web services using HTTP methods.💡 參考解答：Representational State Transfer（表現層狀態轉換），一種使用標準 HTTP 方法進行網路服務通訊的軟體架構風格。
  2. What does `response.json()` do in the `requests` library?`requests` 套件中的 `response.json()` 有什麼作用？
    💡 Answer: Parses the JSON-formatted HTTP response body directly into a Python `dict` or `list`.💡 參考解答：直接將伺服器回傳的 JSON 格式內容解析並轉換為 Python 的字典（`dict`）或列表（`list`）。
  3. What is an API Key?什麼是 API Key（API 金鑰）？
    💡 Answer: A unique secret token used by an API server to authenticate your identity and track your usage quota.💡 參考解答：一組由 API 服務商核發的專屬識別密鑰，用來驗證呼叫者身分並計算呼叫額度。
  4. Why must you NEVER hardcode secret API keys directly inside code pushed to public GitHub?為什麼絕對不能把真實的 API Key 直接寫死（Hardcode）在公開的 GitHub 程式碼中？
    💡 Answer: Bots scan public repositories within seconds and can steal exposed keys, leading to unauthorized usage and huge bills.💡 參考解答：網路上的自動化爬蟲會在幾秒內掃描公開的 GitHub 儲存庫，一旦金鑰外洩就會被盜用並產生高額帳單或資安風險。
  5. What does passing `params={'q': 'Taipei', 'units': 'metric'}` to `requests.get()` do?在 `requests.get(url, params={'q': 'Taipei', 'units': 'metric'})` 中傳入 `params` 會做什麼？
    💡 Answer: Automatically URL-encodes and appends the query string `?q=Taipei&units=metric` to the request URL.💡 參考解答：自動進行網址編碼，並在請求網址後方接上查詢字串 `?q=Taipei&units=metric`。
  6. What HTTP status code indicates 'Unauthorized' (invalid or missing API key)?哪一個 HTTP 狀態碼代表「未授權（Unauthorized，通常是 API Key 無效或未帶）」？
    💡 Answer: HTTP `401 Unauthorized`.💡 參考解答：HTTP `401 Unauthorized`。
  7. What HTTP status code indicates 'Too Many Requests' (rate limit exceeded)?哪一個 HTTP 狀態碼代表「請求次數過多（超過呼叫頻率上限 Rate Limit）」？
    💡 Answer: HTTP `429 Too Many Requests`.💡 參考解答：HTTP `429 Too Many Requests`。
  8. How do you safely read an environment variable `'API_KEY'` in Python?在 Python 中如何安全地從作業系統環境變數讀取 `'API_KEY'`？
    💡 Answer: Use `os.environ.get('API_KEY')`.💡 參考解答：匯入 `os` 模組後使用 `os.environ.get('API_KEY')`。
  9. What is the primary difference between an HTTP `GET` request and a `POST` request?HTTP 的 `GET` 請求與 `POST` 請求最主要的差別是什麼？
    💡 Answer: `GET` retrieves data from the server via URL parameters; `POST` sends a data payload in the request body to create or process resources.💡 參考解答：`GET` 用於從伺服器讀取資料（參數帶在網址列）；`POST` 則將資料封裝在請求本體（Body）中傳送給伺服器（常用於新增資料或呼叫 AI 模型）。
  10. How do you access the string `'Clear'` inside `data = {'weather': [{'main': 'Clear'}]}`?如何從 `data = {'weather': [{'main': 'Clear'}]}` 中取出 `'Clear'`？
    💡 Answer: `data['weather'][0]['main']` — first access the `'weather'` list, then index `[0]`, then key `'main'`.💡 參考解答：`data['weather'][0]['main']` —— 先取 `'weather'` 列表，再用 `[0]` 取出第一個字典，最後取 `'main'`。
