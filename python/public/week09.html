📝 10 Knowledge Quizzes📝 10 題隨堂知識測驗

  1. What does `open('file.txt', 'r')` do, and what happens if the file is missing?`open('file.txt', 'r')` 的作用是什麼？若檔案不存在會發生什麼事？
    💡 Answer: Opens the file in read-only mode. If the file does not exist, Python raises a `FileNotFoundError`.💡 參考解答：以唯讀模式開啟檔案。若該檔案不存在，Python 會拋出 `FileNotFoundError` 例外錯誤。
  2. Why is the `with open(...) as f:` statement strongly recommended over manual `f.close()`?為什麼強烈建議使用 `with open(...) as f:` 而非手動呼叫 `f.close()`？
    💡 Answer: Because the `with` context manager automatically closes the file as soon as the block exits, even if an exception occurs inside.💡 參考解答：因為 `with` 環境管理器會在區塊結束時（即使中途發生錯誤）自動安全關閉檔案，防止資源洩漏或檔案損毀。
  3. What is the critical difference between `'w'` mode and `'a'` mode?開啟檔案時，`'w'` 模式與 `'a'` 模式有什麼關鍵差別？
    💡 Answer: `'w'` (write) erases and overwrites any existing file content; `'a'` (append) preserves existing content and writes new data at the end.💡 參考解答：`'w'`（寫入）會清空並覆蓋原有檔案內容；`'a'`（附加）則會保留舊內容，將新資料接續寫在檔案最尾端。
  4. What does `f.readlines()` return?`f.readlines()` 會回傳什麼結構？
    💡 Answer: A `list` of strings, where each element is one line from the file.💡 參考解答：一個由字串組成的列表（`list`），列表中的每個元素對應檔案中的一行文字。
  5. What is the advantage of `csv.DictReader` over `csv.reader`?處理 CSV 時，`csv.DictReader` 相比 `csv.reader` 有什麼優勢？
    💡 Answer: `csv.DictReader` uses the first header row as keys so you can access columns by name (`row['score']`) instead of fragile column numbers (`row[1]`).💡 參考解答：`csv.DictReader` 會自動將第一列標題作為字典的 Key，讓你用直覺的欄位名稱（如 `row['score']`）取值，而非容易記錯的索引數字。
  6. What is the difference between `json.dump()` and `json.dumps()`?`json.dump()` 與多了一個 s 的 `json.dumps()` 有何差別？
    💡 Answer: `json.dump(obj, file)` writes JSON directly into an open file; `json.dumps(obj)` returns the JSON as a string in memory.💡 參考解答：`json.dump(obj, file)` 會直接將資料寫入檔案物件中；`json.dumps(obj)` 則是將資料轉為記憶體中的 JSON 字串（string）。
  7. Why should we always specify `encoding='utf-8'` when opening text files on Windows?在 Windows 系統讀寫含有中文字的檔案時，為什麼務必加上 `encoding='utf-8'`？
    💡 Answer: Windows defaults to legacy code pages (`cp950`), which corrupts UTF-8 characters and emojis. `encoding='utf-8'` ensures universal compatibility.💡 參考解答：因為 Windows 預設可能使用舊版 `cp950` 編碼，容易導致 UTF-8 中文字或 Emoji 變成亂碼；指定 `encoding='utf-8'` 可確保跨平台零亂碼。
  8. When writing a CSV file on Windows, why do we add `newline=''` inside `open()`?在 Windows 寫入 CSV 檔案時，為什麼要在 `open()` 加上 `newline=''` 參數？
    💡 Answer: To prevent the `csv` module from inserting extra blank lines between rows on Windows (`\r\n` issue).💡 參考解答：為了防止 Windows 的換行符號轉換機制導致 CSV 每列之間多出一行空白列。
  9. What is the main advantage of storing data in JSON over CSV?將資料儲存為 JSON 格式相比 CSV 格式有什麼主要優勢？
    💡 Answer: JSON natively supports hierarchical/nested structures (lists inside dicts, booleans, numbers), while CSV only supports flat 2D tables.💡 參考解答：JSON 原生支援階層式與巢狀結構（例如字典裡包列表、布林值與數值型態），而 CSV 僅適合平面二維表格。
  10. How do you prevent `json.dump()` from escaping Chinese characters into `\uXXXX` codes?使用 `json.dump()` 時，如何讓中文字直接原樣輸出而不被轉成 `\uXXXX` 編碼？
    💡 Answer: Pass `ensure_ascii=False` to `json.dump()` or `json.dumps()`.💡 參考解答：傳入參數 `ensure_ascii=False` 即可保留原樣中文字符。
