# 🚀 Stellark Academy Workspace Organization

Welcome to the organized workspace for **Stellark Academy**! This structure is designed to help you find course materials, labs, and automation scripts efficiently.

## 📂 Folder Structure

| Folder/File | Description |
| :--- | :--- |
| `index.html` | **Main Homepage** of Stellark Academy. |
| `content/` | Core configuration and metadata (e.g., `homepage.json`). |
| `public/` | Deployment-ready HTML files (`week01.html` to `week18.html`) and visual assets. |
| `src/` | Frontend logic, styles, and utility functions. |
| `Labs/` | Project-specific lab exercises and quiz data. |
| `Scripts/` | Python automation tools for syncing labs, translation, and deployment. |
| `Docs/` | Project-specific documentation and SOPs. |

## 🛠️ Key Components
- **Curriculum**: 18 weeks of Python PBL (Project-Based Learning) focusing on building a Snake Game.
- **Automation**: Scripts in `/Scripts` handle the lifecycle of content generation and verification.
- **Branding**: Visual assets and UI/UX standards are maintained within the `Public/assets` directory.
